# tab-number

A [herdr](https://herdr.dev) plugin that prefixes every tab with its position: `1. {tab_name}`. Numbers are recalculated whenever a tab is created, closed, moved or renamed.

Requires herdr 0.9.0+ and `jq`.

## Install

```sh
herdr plugin link /path/to/tab-number
```

## Uninstall

```sh
herdr plugin unlink tab-number
```
